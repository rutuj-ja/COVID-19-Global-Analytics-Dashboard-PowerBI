# COVID-19 Global Analytics Dashboard
![COVID-19 Dashboard](Screenshot%202026-07-08%20195402.png)

An interactive COVID-19 analytics dashboard developed using Microsoft Power BI to analyze global COVID-19 cases, deaths, recoveries, and trends.

## 📊 Dashboard Overview

This Power BI dashboard provides an interactive view of COVID-19 data and helps analyze important trends and key performance indicators.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization
- Interactive Dashboard

## 📌 Key Features

- Total COVID-19 Cases
- Total Deaths
- Total Recovered Cases
- Active Cases
- COVID-19 Trend Analysis
- Date-based filtering
- Interactive charts and visuals
- KPI cards for quick analysis
- User-friendly dashboard interface

## 🎯 Project Objective

The objective of this project is to transform COVID-19 data into meaningful insights using Power BI and present the analysis through an interactive and easy-to-understand dashboard.
